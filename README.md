# 🌐 Momin — Personal Portfolio & Interactive Showcase

![Momin Portfolio Banner](assets/images/hero_bg.jpg)

A sleek, modern, interactive dark-mode personal portfolio website for **Momin** — Web Designer, Blogger & Trend Analyst. Designed with a luxury cyber aesthetic, fluid animations, dynamic accent color switching, and fully responsive layouts.

---

## ✨ Features

- 🎨 **Luxury Dark Theme & Custom Glow Cursor**: Smooth cursor follower with ambient background glow and typography built on *Syne*, *Plus Jakarta Sans*, and *Space Grotesk*.
- ⚙️ **Real-Time Accent Customizer**: Floating gear menu allowing users to switch theme accent palettes instantly (Neon Green, Electric Cyan, Cyber Purple, Laser Amber).
- 💼 **Interactive Project Showcase**: Dynamic billboard display for featured works (WebGL 3D graphics, E-Commerce, and Web3 dashboards).
- 🛠️ **Filterable Templates & Services Tab**: Showcase grid with category filtering (*All*, *Branding*, *Visual Identity*) and detailed interactive service breakdowns.
- 📱 **100% Mobile Responsive**: Fluid layout adapted seamlessly for all desktop, tablet, and mobile viewport sizes.
- 📬 **Project Inquiry Modal & One-Click Contact**: Built-in popup modal for project inquiries and click-to-copy email functionality with custom toast notifications.

---

## 🛠️ Built With

- **HTML5**: Semantic markup & SEO structured metadata.
- **CSS3**: Custom CSS variables, glassmorphism, keyframe animations, grid/flexbox layouts.
- **JavaScript (ES6+)**: Pure Vanilla JS application logic for state, event handling, dynamic DOM rendering, and cursor animations.
- **React / JSX (Optional)**: Framer Motion compatible application template (`js/app.jsx`).

## 🚀 Getting Started

### Prerequisites

No complex build steps or node modules required! You can open the project directly in any web browser.

### Option 1: Open Directly in Browser
Simply open the `Portfolio` folder and double-click `index.html`.

### Option 2: Run Local Development Server
Using Python (Pre-installed on Windows/macOS):
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

Using VS Code:
Right-click `index.html` and choose **Open with Live Server**.

---

## 🌐 Deploy to Vercel

1. Push this repository to your GitHub account ([github.com/Mominmajeed](https://github.com/Mominmajeed)).
2. Go to **[Vercel](https://vercel.com)** and click **Import Project**.
3. Select this repository and click **Deploy**.

Alternatively, deploy via Vercel CLI:
```bash
npx vercel
```
